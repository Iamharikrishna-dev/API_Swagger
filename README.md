# QuickPay Swagger API

Interactive API documentation for QuickPay using Swagger UI.

## Install Dependencies

```bash
npm install
```

## Run Swagger

```bash
npm run api
```

## Open in Browser

http://localhost:9000

## API Specification

`quickpay-openapi.yaml`

**Note:** The QuickPay backend must be running to test API endpoints using **Try it out**.
